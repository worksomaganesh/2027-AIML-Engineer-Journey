# Internship Role Map — First-Year B.Tech AIML

This is a role-discovery guide, not a promise of eligibility. Every opening must be checked individually for year of study, graduation date, location, work authorization, duration, hours, required skills and stipend.

|---|---|---|---|---|
| A | Python Developer Intern, Automation Intern, Scripting Intern | Automate tasks, parse files/data, integrate APIs, fix bugs | Smart File Log Analyzer, clean Python code, tests, Git | Strong practical target where posting accepts beginners |
| A | Data Analyst Intern, Data Intern, Business Analyst Intern (technical) | SQL queries, clean data, analysis, dashboards and findings | E-commerce Analytics project, SQL queries, charts and written insights | Practical target; Excel/SQL often matter |

## Shared skill expectations

Most entry-level technical roles benefit from:
- One language used confidently (Python for this plan).
- Git/GitHub and ability to read existing code.
- Problem-solving and debugging.
- Clear communication and a concise project explanation.
- Basic testing, documentation and reliable follow-through.
- Evidence: runnable projects, tests, sample outputs and honest limitations.

Role-specific additions:
- **Data:** SQL, spreadsheets, pandas, data cleaning, charts and reasoning.
- **SWE/backend:** DSA, HTTP/JSON, APIs, databases, tests and error handling.
- **AI application:** API integration, prompt/output validation, retrieval basics and failure evaluation.
- **ML/data science:** statistics, train/test separation, baselines, appropriate metrics and error analysis.
- **QA automation:** test cases, bug reproduction, API testing and pytest.

## Company and posting research checklist

Do not infer eligibility from a company name or an old posting. Search the official career page and read the exact role. For each opening, record:
1. Official URL and date checked.
2. Exact title and location.
3. Eligible graduation years / current year of study.
4. Required skills and any experience prerequisites.
5. Work mode, duration, weekly hours and start date.
6. Stipend/pay, contract terms and whether it is an actual internship.
7. Application deadline and required documents.
8. Evidence from your repo that matches each requirement.

### Big-company strategy

Meta, Anthropic, NVIDIA, Google, OpenAI, SpaceX, IBM, Microsoft and Deloitte are aspirational targets, not one shared eligibility category. Some internships are designed for penultimate-year students, some are research-specialist roles, and some teams may list different criteria. Apply only where the actual opening accepts your profile; don't make the whole plan depend on these employers.

### Legitimate opportunity checks

- Prefer official company career pages or verified platform listings.
- Never pay a recruiter or platform to secure an offer/interview.
- Check company domain, supervisor, duties, duration, stipend, contract and how work will be evaluated.
- Be cautious of unpaid full-time work with vague deliverables, requests for sensitive documents too early, or pressure to buy training/certificates.
- Virtual simulations and course certificates can support learning but are not equivalent to a real employment internship.
- Keep private contact details and application documents out of a public repository.
